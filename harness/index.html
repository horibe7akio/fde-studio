3Dでわかる / ハーネス

ハーネスは、なぜ
毎日組み直すのか。

AIに仕事を頼むとき、自分では変えられないものと、自分で書くものがあります。その違いを、サッカーの作戦ボードで見ていきます。

先に結論を書くと、とある試合で最適なハーネスは、他の試合で最適とはかぎらない、ということです。

SCROLL

01 / 3つの層

選手、ルール、作戦ボード。

AIの仕事は、3つの層でできています。

  • 選手モデル（Claude）。できるのは、次に何をするかを文字で答えることだけです。
  • ルールとスタジアム公式の言うハーネス（Claude Code そのもの）。選手の答えを受けて、ファイルを読む、書く、コマンドを打つ、を実際にやる仕組みです。
  • 作戦ボード自分で書く設定。CLAUDE.md、メモリ、スキル、フックです。試合の前に、選手に渡されます。

02 / この世のことわり

公式のハーネスは、書き換えられない。

AIを動かす仕組み、使える道具、会話の中で何を覚えておくかの管理、安全のための歯止め。作っているのはAnthropicで、使う側には書き換えられません。サッカーでいえば、競技のルールそのものです。

回せるのは、用意されたツマミだけです。

  • モデル
  • 考える深さ
  • 許可
  • 道具

Anthropicの説明では、ハーネスは「モデルの周りのソフトウェア一式。ループ、道具、文脈の管理、ガードレール」です。

03 / ことわりも変わる

ルールは、向こうから変わる。

Anthropicの更新で、ときどきルールが変わります。サッカーにVARが入ったように、Claude Code には v2.1.283 で「/doctor prompt-audit」が入りました。CLAUDE.md やスキルの中から、古いモデル向けの書き方や、食い違う指示を探す検査です。

選手も成長します。新しいモデルになると、弱点を補うために書いていた細かい指示が要らなくなり、残しておくと、かえって足を引っぱります。

Anthropicは、モデルが一段よくなるたびに、ハーネスに込めた前提を試し直すように、と書いています。

04 / 作戦ボードは2種類

全部の試合で読むボードと、案件ごとのボード。

自分で書く作戦ボードには、全部の試合で読む共通の1枚（全体用の CLAUDE.md）と、その案件の試合だけで読むボード（案件ごとの CLAUDE.md）があります。

公式には、ファイルの種類ごとに効くルールや、必要なときだけ読むスキルもあります。効く範囲を絞るための仕組みです。

05 / 困るたびに足す

攻撃的にしようとして、8-1-1にはしない。

困ったことが起きるたびに、作戦を足していく。足しているときは、どれも正しいんです。

でも、全部の試合で読む共通のボードに足し続けると、全部の案件の注意書きを足し合わせた、最大公倍数のようなハーネスに膨らみます。サッカーなら、誰もそんなフォーメーションにはしません。けど、ハーネスは、そういうことをしようとしてしまうんです。

ピッチに立てるのは11人だけ。AIが一度に気にかけられることにも、限りがあります。

公式の目安は、CLAUDE.md 1ファイルにつき200行以内。長いほど守られにくくなり、矛盾するルールはどちらかを勝手に選ぶことがある、とあります。

06 / 試合ごとの最適

とある試合で最適なハーネスは、他の試合で最適とはかぎらない。

強い相手には、守りを固めた5バックが正しい。でも、同じ5バックのまま引いて守る相手と戦ったら、点が取れません。ハーネスも同じで、ある案件のために入れた作戦が、別の案件では足を引っぱります。

  • 4-3-3VS ゲーム制作
  • 5-4-1VS アプリ開発
  • 4-4-2VS 資料づくり
  • 3-5-2VS 広報

07 / 審判

書いても守られないことは、審判を置く。

作戦ボードに書くだけでは、守られないことがあります。そこで、AIの行動を途中で止める仕掛け（フック）を置きます。サッカーでいえば審判です。

ただし、何でも笛を吹く審判だと、試合が止まります。どこまで笛を吹くかは、人が決めます。

公式にも、CLAUDE.md は強制ではなく文脈として扱われるので、必ず止めたいときはフックを使うように、とあります。

08 / まとめ

変えられないルールの上で、作戦を組み直す。

ルールとスタジアムは、Anthropicが作り、ときどき変えます。こちらにできるのは、ツマミを回すことと、作戦ボードを書き直すことです。

毎日の調整は、ルールを増やす作業ではなく、増えた作戦の効く範囲を絞る作業です。
